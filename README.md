# DSA in Java – Part 15: Dynamic Programming

This repository contains my Java implementations and problem-solving practice focused on **Dynamic Programming (DP)**, covering advanced concepts and optimization techniques to solve complex algorithmic problems efficiently.

## 📚 Topics Covered

- Advanced Dynamic Programming Concepts
- Recursion, Memoization and Tabulation
- Space Optimization in DP
- 0/1 Knapsack Variations
- Unbounded Knapsack
- Subset Sum Problem
- Equal Sum Partition
- Minimum Subset Sum Difference
- Longest Common Subsequence (LCS)
- Longest Common Substring
- Longest Increasing Subsequence (LIS)
- Edit Distance
- Matrix Chain Multiplication
- DP on Strings
- Practice Problems Based on Dynamic Programming

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Dynamic Programming, Recursion, Memoization, Tabulation, Optimization, Arrays, Strings

## 🎯 Learning Objectives

- Strengthen understanding of advanced DP patterns.
- Convert recursive solutions into optimized DP solutions.
- Apply memoization and tabulation effectively.
- Optimize time and space complexity.
- Improve problem-solving skills for competitive programming and technical interviews.
